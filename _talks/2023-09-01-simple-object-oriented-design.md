Nesta palestra, abordarei sete práticas de codificação que têm me ajudado a projetar sistemas de software orientados a objetos de fácil manutenção. Como você verá, eles não são novos em si, mas todos têm meu toque pragmático pessoal.

* Aprenda como criar sistemas simples orientados a objetos!
* Gerencie o crescimento da complexidade em projetos orientados a objetos
* Escreva código simples
* Mantenha os objetos consistentes em todos os momentos
* Gerenciar dependências adequadamente
* Projete abstrações flexíveis
* Modularizar grandes sistemas

Esta palestra é perfeita para engenheiros que conhecem programação orientada a objetos. Esta palestra também é um resumo do meu livro [Simple Object-Oriented Design](https://www.simple-object-oriented-design.com/), publicado pela Manning.
