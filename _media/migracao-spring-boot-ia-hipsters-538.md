Neste episódio do Hipsters.tech, conversamos sobre como usamos agentes de IA para migrar a plataforma da Alura do Spring Boot 2 para o 4.

A conversa passa por testes automatizados, revisão de código, validação humana, deploy e pelos desafios de atualizar um sistema em produção.

Participam Paulo Silveira, Vinny Neves, Maria Eduarda Rodolfo, Carlos “Cadu” Müller e eu.

O caso também está no artigo [Como migramos do Spring Boot 2 para o 4 com ajuda de IA]({{ '/conteudo/migracao-spring-boot-com-ia/' | relative_url }}), escrito com Carlos Müller.
