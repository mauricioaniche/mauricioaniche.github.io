public void add(int element) {
    if(size == elementData.length) // it's full!
        resize();

    elementData[size] = element;
    size++;
}

private void resize() {
    Object[] newArray = new Object[elementData.length * 2];
    for(int i = 0; i < elementData.length; i++) {
        newArray[i] = elementData[i];
    }
    elementData = newArray;
}

Add in a linked list

public void add(int element) {
    Node newNode = new Node();
    newNode.element = element;

    if(end==null) { // list is empty
        start = newNode;
        end = newNode;
    } else {
        end.next = newNode; // link to the new one
        end = newNode; // newNode is the 'end'
    }
}

public int get(int position) {
    Node current = start;
    while(position > 0) {
        current = current.next;
        position--;
    }

    return current.element;
}

There's no silver bullet!

What you learned today?

  • Understanding data structures is fundamental for a software engineer
  • Data structures are different from each other (implementation, runtime)
  • ArrayLists use arrays internally. They take constant time for get() and add(), but not for addFirst()
  • LinkedLists connect elements to their next ones. They take constant time for add() and addFirst(), but not for get()
