A documentação de APIs populares está espalhada por vários formatos, desde documentação de referência com curadoria de fornecedores até threads Stack Overflow. Para os desenvolvedores, muitas vezes não é óbvio de onde uma determinada informação pode ser recuperada. Para entender esse cenário de documentação, conduzimos sistematicamente pesquisas no Google pelos elementos de dez APIs populares. Descobrimos que sua documentação está amplamente dispersa entre muitas fontes, que GitHub e Stack Overflow desempenham um papel proeminente entre os resultados da pesquisa e que a maioria das fontes documenta rapidamente novas funcionalidades de API. Essas descobertas informam os fornecedores de API sobre onde os desenvolvedores encontram documentação sobre seus produtos, informam os desenvolvedores sobre locais onde procurar documentação e permitem que os pesquisadores estudem mais detalhadamente o cenário da documentação de software.
