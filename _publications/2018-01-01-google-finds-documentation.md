title: "Where does Google find API documentation?"
link: "https://research.tudelft.nl/en/publications/where-does-google-find-api-documentation"
authors: "Christoph Treude, Maurício Aniche"
conference: "2nd International Workshop on API Usage and Evolution"
abstract: "API documentation are spread everywhere on the internet. We understand the document landscape by analyzing where Google searches for the elements of 10 popular APIs. We found that their documentation is widely dispersed among many sources, that GitHub and Stack Overflow play a prominent role among the search results, and that most sources are quick to document new API functionalities."
